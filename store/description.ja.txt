Agent セッション、メール、チャットを G2 で読む。話して、Bluetooth キーボードで打って、画像も開ける。

HUD Desk（旧名 Orca Glass）は G2 を、Windows PC の Orca で動くエージェント、Gmail、Beeper のチャットにつなぎます。一番上の行でコーディング・メール・チャットを切り替えます。

コーディング:
- Claude、Codex、Cursor、OpenCode、Pi、OpenClaude、Hermes Agent のセッションをモデル名と状態つきで表示。Orca のチャットセッションは閲覧のみ。
- エージェントと作業場所で絞り込み。Codex・Claude・Cursor の使用量をバーで表示。
- 長押しで話す: PC 上の Whisper で文字にして、確認してから送信。番号付きの選択肢にも回答。

メール（Gmail）:
- メールボックスを 1 つずつ表示。ラベルで絞り込み（音声または入力で検索）。スレッドを開くと既読に。
- キーボードで作成・返信・全員に返信・転送・アーカイブ・削除・スター・元に戻すを Gmail のキーで。下書きはメガネに表示され、確認してから送信。
- メール内の画像（ニュースレターの画像も）を表示。

チャット（Beeper: WhatsApp、Signal、Telegram など）:
- 各行に日付とアプリ名。ネットワークで絞り込み。書式も保ったまま表示。
- ボイスメッセージを文字起こし（広東語に調整済み）。各行の下に英訳。写真もメガネで開ける。

画像: G2 向けに調整した元画像、AI ラベル（グラフの文字をくっきり描き直す）、拡大（区画ごと）、AI 読み取り（PC 上のビジョンモデルが画像を説明）。

キーボード: どこでも Gmail 風のキー。VS Code 風の Ctrl+P、Ctrl+Shift+P、Ctrl+Tab、Ctrl+F。? ですべてのキーを表示。

リーダー: 本のようなページ表示。ネイティブ文字、またはピクセルフォント（Scientifica 5x11 で 114 桁まで）。中国語・日本語にも対応。自分の発言の背景（線、点、Tube 走査線、左バー、下線）とアプリの明るさを選べます。英語・日本語。

必要なもの: G2、Even Realities アプリ（iPhone は未確認）、Orca、Tailscale 経由で PC 上のブリッジ。任意の PC 向けのセットアップはまだ提供していません。エージェント、メール、チャット、音声、AI はすべて PC 上で動きます。PC がなくてもデモを試せます。
